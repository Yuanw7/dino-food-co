# TapTap Android 发布准备

核对日期：2026-10-18。目标为 TapTap 中国站手机游戏。以下是工程与材料工作清单，不代表平台批准或资格判定。最终以开发者后台适用要求、官方最新文档及审核反馈为准。

## 路径选择

官方区分预约/敬请期待、测试、正式上线。预约不强制上传 APK；开启测试或正式上线需上传 APK，并完善适用资质。建议先准备预约与免费测试，避免把“网页可玩”当作安装包已通过审核。

对暂未获版号、无法办理相关游戏备案/核准的项目，官方提供测试辅助证明申请路径；需按当前后台条件申请，不是免资质通道，也不保证一定获批。无版号不要接入内购计费。

来源：[新建和管理游戏](https://developer.taptap.cn/docs/store/release/publish/create-game/)、[开发者快速入门](https://developer.taptap.cn/docs/store/standardies-operation/)、[APP 核准常见问题](https://developer.taptap.cn/docs/en/store/release/policy/filing-faq/)。

## 技术验收

- [ ] 确认正式名称、合法运营主体、唯一包名；不是打包工具默认包名；平台包名与 APK 一致。
- [x] 已安装依赖、生成 package-lock.json，npm run check 通过。
- [ ] 干净环境 npm ci 可复现构建。
- [x] 已生成 android/ 原生工程；后续使用 android:sync。
- [ ] 将源码与原生工程提交到版本管理，配置本机 Java 和 API 36 SDK 并通过 Gradle 构建。
- [ ] 使用 Android Studio 配置 release 签名；密钥在仓库外保管并备份。不得用 debug 或公用证书发布。
- [ ] 在原生工程确认 versionCode 非零且更新递增、versionName 与商店资料一致；npm 版本不会自动同步原生版本。
- [ ] 自有签名 release APK 可安装；升级覆盖保留纪录；离线冷启动、杀进程重开、清除记录正常。
- [ ] 真机检查触控、返回键、切后台/锁屏/来电、旋转、刘海安全区、WebView 兼容性和连续三天合同。
- [ ] 低端与主流 Android 真机记录帧率、内存、发热、ANR/崩溃；修正首关难度与文本裁切。
- [ ] 检查最终合并 AndroidManifest 的权限和实际 SDK 列表；隐私描述与实际数据处理一致。
- [ ] 若当前发行方式要求实名认证、防沉迷或其他服务，按官方要求原生接入并在真实安装包验证；目前尚未接入 TapSDK。

来源：[审核规范](https://developer.taptap.cn/docs/store/release/publish/agree/)、[Capacitor 安装](https://capacitorjs.com/docs/getting-started)、[Android 环境](https://capacitorjs.com/docs/getting-started/environment-setup)。

## 平台与资料验收

- [ ] 完成开发者账号注册/认证，确认自研或授权关系。
- [ ] 根据发布类型提供后台要求的版号、软著、备案/核准、授权等材料；缺项先确认是否适用测试申请路径。
- [ ] 准备原创图标、横竖截图、实机视频、简介、玩法说明、支持设备与更新日志；规格以提交时后台为准。
- [ ] 正式隐私政策补齐主体、联系方式、生效日期、数据处理说明及适用的未成年人条款，并有可访问链接和游戏内入口。
- [ ] 若加入第三方 SDK，补齐 SDK 清单、用途与隐私链接，按适用要求安排同意前后初始化；清查默认权限。
- [ ] 提交真实可复现的测试说明与必要测试账号（当前原型无账号）。
- [ ] 预约、测试、正式发行分别记录审核结果；反馈修复后复测再提审。

## 首版商店文案草稿

名称：地底打工龙（暂定，待核名）。

一句话：陨石之后，在岩缝里为下一顿饭打工。

介绍：陨石摧毁地表，恐龙躲进地下。你受雇于恐龙食物公司，用可转弯的管状抓手绕过岩石、采集藻类和巨型植物。每天工作 60 秒，每三天交齐口粮额度，才能保住地下床位。键盘和触屏方向控制均可玩。

0.2.0 更新说明：新增恐龙角色、地下裂隙地图、四类食物与素材包 UI；改为分段管线操作与三日食物合同；新增达标续约和未达标遣返结局。

新增发行事项：核验 Dino Characters 包的原作者许可；保留 Crusenho UI 的署名、作者链接与 CC BY 4.0 许可。见 ASSETS.md。

此文案描述原型，不应在真机与审核完成前宣称已正式发行。
